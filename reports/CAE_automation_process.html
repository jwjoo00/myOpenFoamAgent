CAE AUTOMATION · 자동화는 어떻게 작동하는가

엔지니어의 한 문장이, 완성된 CFD 해석으로

핵심은 "정확도"가 아니라 자동화의 형태입니다. AI가 작업을 어떻게 단계로 쪼개고, 어떤 도구를 호출하고, 결과를 보며 다음을 결정하는지 — 그 과정을 실제 사례로 보여드립니다.

"DTMB 프로펠러 추력 구해줘" → 형상·격자·솔버·결과·리포트 전부 자동

🔄자동화의 형태 — "Tool-use 루프"

고정 스크립트가 아닙니다. AI가 매 단계 결과를 관찰하고 다음 행동을 스스로 결정하는 반복 루프가 자동화의 핵심 형태입니다.

⚙️자동화 파이프라인 — 6단계

사람이 손으로 하던 CFD 워크플로의 각 단계를, AI가 도구를 호출해 자동 수행합니다.

STEP 4

🔬실증 — 실제 사례 A: 프로펠러 (회전기계)

"DTMB 프로펠러 성능 구해줘" 한 문장에서, AI가 실제로 거친 자동화 단계입니다.

사례 A · DTMB 4119CAD 없음 → 형상부터 검증까지 전자동
1
형상 생성generate_propeller

CAD 파일 없이 공개 오프셋표(NACA66 단면)에서 3-블레이드 프로펠러를 직접 생성 → watertight STL.

▲ 1단계 산출물 — 자동 생성된 형상
2
회전영역 격자run_snappy_mesh

프로펠러를 감싸는 회전영역(cellZone) 실린더를 자동 생성하고 격자화 (~115,000 셀).

3
MRF 회전 설정scaffold_mrf

회전 좌표계·RPM·축을 설정. 회전벽을 MRFnoSlip으로 자동 지정(이게 빠지면 블레이드가 안 돈다 — 자동화에 내재된 노하우).

4
병렬 실행run_solver

14코어 자동 병렬. 잔차가 수렴하면 스스로 정지 — 고정 반복수가 아니라 수렴-주도.

5
성능 추출rotor_performance

축방향 추력·토크·효율을 자동 계산 → 추력 126N, Kt 0.146, η₀ 0.57.

6
진단 리포트 생성rotor_report

회전기계는 사람 검토가 중요 → 형상·유동/회전/추력 방향·성능·체크리스트를 한 장으로 자동 시각화.

▲ 6단계 산출물 — 사람-판단용 자동 진단 리포트
✓
자동 검증 · 기록find_similar_runs

결과를 문헌(Jessup 1989)과 비교하고, 전 과정을 DB에 레시피로 기록 → 다음 유사 케이스에서 재사용.

🔥실증 — 실제 사례 B: 공액 열전달 (CHT)

고체+유체 결합 해석도 같은 자동화 형태. 한 도구가 다단계 파이프라인을 자동 실행합니다.

사례 B · multiRegion CHT고체·유체 region 분리 → 결합 해석
1
케이스 복사copy_case

다영역 CHT 튜토리얼을 시작점으로 복사 후 목적에 맞게 적응.

2
자동 파이프라인 실행run_cht

한 번의 호출로 격자 → 고체/유체 region 분리(splitMeshRegions) → 결합 솔버(foamMultiRun)를 순서대로 자동 실행. 세 가지 메싱 경로(cellZone·setup·extrude) 자동 지원.

3
온도장 후처리cht_report

region별 온도장을 자동 시각화 + 정량(min/max/mean) 추출.

▲ 3단계 산출물 — 자동 생성 온도장 (고체→유체 열전달)

🧠왜 "스크립트"가 아니라 "에이전트"인가

자동화가 단순 매크로와 다른 점 — AI가 결과를 보고 판단·자가수정합니다.

수렴을 스스로 판단

고정 반복수가 아니라 잔차·힘(force)이 평평해질 때까지 보고 정지 시점을 결정.

예) 미수렴(timeout)이면 "결과 아님"으로 표시하고 연장 판단

오류를 진단·교정

메시 품질이 나쁘면 알고리즘·스무딩을 바꾸고, 추력 부호가 이상하면 설정을 의심.

예) "추력이 음수네?" → MRF 회전벽 설정 버그를 진단으로 추적

과거에서 학습

모든 run을 DB로 축적 → 유사 케이스의 수렴 반복수·레시피를 재사용해 다음을 빠르게.

예) 같은 형상·Re의 과거 수렴값으로 실행 상한 자동 설정

사람 판단을 지원

애매한 영역(회전기계·메시 품질)은 진단 리포트로 시각화해 엔지니어 검토를 돕는다.

예) 형상·방향·단면을 한 장으로 보여줘 "사람이 1초에 판단"
✋ 사람의 자리 — 통제권은 엔지니어에게

비가역·실행 동작(메시·솔버 실행, 설정 변경)은 실행 전 사람 승인을 거칩니다. AI는 무엇을 왜 하는지 먼저 설명하고, 엔지니어가 핵심 갈림길에서 방향을 정합니다. 자동화는 속도를, 사람은 판단을 맡는 구조입니다.
